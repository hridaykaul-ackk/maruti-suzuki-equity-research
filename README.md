# Maruti Suzuki (NSE: MARUTI) — Mini Equity Note: Margin Trend Analysis & Relative Valuation

Independent equity research project on Maruti Suzuki India Ltd, built as an 
intensive multi-day sprint as part of my B.Com (Hons.) coursework at SRCC.

**Core question this project answers:** Is Maruti's slowing profit growth 
(PAT growth: 114% → 64% → 8% → 1% over FY23-FY26) a temporary blip or a 
structural margin problem — and does the current valuation already reflect 
that risk?

## Scope
This is a focused "Mini Equity Note,"
It prioritizes depth and defensibility over breadth: every number is traced 
to a primary source, and open questions are flagged honestly rather than 
guessed at.

## Progress
- ✅ 5-year historical financials (FY22-FY26), standalone P&L
- ✅ Revenue driver & margin waterfall analysis
- ✅ Comparable company analysis (Tata Motors, M&M, Hyundai India) — in progress
- ✅ Investment thesis (1-2 pages)

## Methodology notes
- All figures are Standalone (not Consolidated), for consistency across years
- All data cross-checked against the audited Standalone Statement of Profit 
  and Loss in each year's Annual Integrated Report — not summary/notes pages, 
  which can have formatting inconsistencies across report vintages
- Blue cells = sourced data; black bold = formulas; yellow = pending input
- Open questions (e.g. the FY25 materials-cost jump) are documented as 
  unresolved rather than explained away
